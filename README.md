🏦 Microfinance Management System (MMS)

A full-stack Microfinance Management System designed to manage customers, loans, repayments, deposits, withdrawals, users, and reporting with a scalable and clean architecture approach.

This repository is for portfolio and interview demonstration purposes only.

🎯 Project Objective

This system aims to digitize and streamline microfinance operations, ensuring:

Accurate customer and loan management

Transparent financial tracking

Secure admin-controlled processes

Modular and scalable system architecture

🚀 Core Features
👤 Customer Management

Step-by-step customer onboarding

Personal, contact, employment, financial & guarantor information

Read-only customer profile view for data verification

Status tracking (Active / Inactive / Blacklisted)

💰 Loan Management

Multiple loan plans with dynamic rules

Loan amount validation based on plan & department

Loan application wizard (multi-step)

Loan summary preview before final submission

Terms & conditions confirmation

Loan agreement generation (downloadable)

💳 Deposit & Withdrawal (Manual Approval System)

Customers submit deposit/withdraw requests

Multiple payment methods (Bank / Wallet)

Admin approval & rejection workflow

Request tracking with status history

🔁 Repayment Management

EMI-based repayment handling

Manual & scheduled repayments

Outstanding balance calculation

Repayment history tracking

📊 Reporting & Dashboard

Loan performance reports

Customer-wise financial summaries

Collection & disbursement tracking

Admin dashboards with key metrics

👥 User & Role Management

User creation with role-based access

Data access level control

Status enable/disable

Secure authentication & authorization

📁 File & Document Handling

Upload documents (NID, statements, signatures)

Base64 conversion & validation

Agreement letter generation with company branding

🧩 Technical Use Cases
Backend (ASP.NET Core Web API)

Clean Architecture implementation

Repository Pattern + Unit of Work

DTO-based request/response handling

LINQ-based dynamic queries

Background processing (long-running tasks)

Caching for performance optimization

Consistent API response structure

Frontend (Angular)

Modular architecture with lazy loading

Reactive Forms with advanced validation

NG-ZORRO UI components

Tailwind CSS for clean UI

Read-only data views

Step-by-step wizard forms

API services separated from components

Database

Relational database design

Normalized tables for financial accuracy

Transaction-safe operations

Referential integrity across modules
